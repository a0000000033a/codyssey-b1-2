# codyssey-b1-2

### 최종 통합 편집 파이프라인 (CapCut)

1. **오디오 트랙 배치:** Suno에서 만든 첼로 베이스 음원을 전체 배경(35초)으로 깔고, ElevenLabs의 나레이션과 추출 효과음을 싱크에 맞게 얹습니다.
2. **비디오 싱크 조절:** 각 씬별 영상 속도를 미세하게 조절하여 내레이션이 끝나는 지점과 화면 전환(디졸브 효과 사용) 타이밍을 일치시킵니다.
3. **멀티 비율 출력:**
* **Version A (유튜브용 16:9):** 생성된 원본 비율 그대로 자막을 하단에 배치하여 렌더링합니다.
* **Version B (숏폼용 9:16):** 프로젝트 비율을 9:16으로 변경한 뒤, 영상들의 정중앙(피사체 중심)을 기준으로 스케일을 키워 꽉 차게 맞춥니다. 중앙 집중형 구도로 촬영되었기 때문에 잘려 나가는 핵심 요소 없이 트렌디한 숏폼 영상으로 변환됩니다. 자막은 가독성을 위해 화면 중앙 하단에 굵게 배치합니다.

### 🛠️ 멀티모달 통합 편집 가이드 (CapCut / Premiere Pro)

1. **화풍 및 캐릭터 일관성 유지:** 모든 Midjourney 프롬프트에 `earthy tones`, `cinematic lighting`, `--style raw`를 공통 적용하여 전체 영상의 색감 밸런스를 단단히 묶었습니다. 인물이 아닌 '원두와 오브제' 중심이므로 화풍 깨짐이 없습니다.
2. **원 소스 멀티 유즈 (16:9 ➡️ 9:16):** 모든 씬의 피사체(나무, 원두, 포타필터, 원두 자루)가 **화면 정중앙**에 오도록 프롬프트를 제어했습니다. 편집 프로그램에서 프로젝트 비율을 `9:16`으로 전환하고 정중앙을 기준으로 스케일을 키우면, 별도의 재작성 없이 트렌디한 숏폼 캠페인 영상이 즉시 완성됩니다.



# [현실적 제작 및 문제 해결 전략] 파이프라인 설계

멀티모달 AI 제작 시 발생하는 고질적인 문제를 해결하기 위한 의사결정 전략입니다.

* **화풍/캐릭터 불일치 해결:** 인물을 전면에 내세우지 않고, **'원두, 대지, 에스프레소 추출, 커피를 마시는 손과 실루엣'** 중심의 시네마틱 매크로 컷으로 기획하여 화풍 튀김 현상을 원천 차단합니다. Midjourney의 `--sref`(스타일 참조) 기능을 활용해 모든 씬의 색감을 고정합니다.
* **해상도·비율 혼재 (16:9 & 9:16 동시 대응) 전략:** 영상 생성 단계에서 **16:9(가로형) 대칭 구도 중심**으로 제작합니다. 피사체를 정중앙에 배치하여 컷 편집 툴(CapCut)에서 9:16으로 크롭(자르기)해도 비주얼이 깨지거나 잘려 나가지 않도록 프롬프트를 제어합니다.
* **오디오 톤 미스매치 방지:** 화려한 일렉트로닉이나 로파이 대신, 대자연과 깊은 풍미를 연상시키는 '어쿠스틱 첼로 선율 + 자연의 소리(바람, 흙, 커피 추출 소리)'로 통일합니다.
